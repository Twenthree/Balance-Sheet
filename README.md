# 💰 Balance Sheet

A financial balance sheet built with HTML and CSS, demonstrating advanced CSS pseudo-selectors and table styling techniques.

## 📖 About
Eighth project from freeCodeCamp's Responsive Web Design certification. A detailed balance sheet showcasing CSS pseudo-selectors, table structures, and financial document styling.

## 🛠️ Built With
- HTML5 (Semantic tables)
- CSS3 (Pseudo-selectors, Advanced styling)

## 💡 Key Learnings
- **CSS Pseudo-selectors** (:nth-child, :not, :first-of-type, :last-of-type)
- Complex table styling
- Semantic HTML for financial data
- Border styling and spacing
- Screen reader accessibility
- Print-style layouts for web
- Financial document structure

## 🎯 Features
- Professional balance sheet layout
- Clean table structure
- Advanced pseudo-selector usage
- Proper financial data formatting
- Accessibility considerations
- Responsive table design
